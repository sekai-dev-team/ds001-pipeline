# Spec: GitHub Trending 源 (v0.5.1)

**状态:** 待实现  
**日期:** 2026-06-02

---

## 需求

为 DS-001 添加 GitHub Trending 作为新信源，每天摄入 GitHub 热门仓库。

## 方案

使用 **[GitHub Trending RSS](https://mshibanami.github.io/GitHubTrendingRSS)** — 一个成熟的第三方 RSS 服务，将 GitHub Trending 页面转换为标准 RSS feed。

- **Feed URL:** `https://mshibanami.github.io/GitHubTrendingRSS/daily/all.xml`
- **格式:** 标准 RSS 2.0（与现有 `_build_rss_fetcher` 完全兼容）
- **频率:** 每日更新（GitHub Actions 驱动）
- **语言过滤:** 如只需特定语言，换成 `daily/python.xml` 等。本次用 `all.xml` 全语言。

## 实现步骤

### 1. 在 `pipeline/sources.yaml` 添加新源

在 `sources:` 列表中添加（放在现有 RSS 源附近即可）：

```yaml
  - name: "GitHub Trending"
    url: "https://mshibanami.github.io/GitHubTrendingRSS/daily/all.xml"
    tag: "source/github-trending"
    window: 24
```

**不需要改任何 Python 代码。** `sources.py` 第 350-363 行的动态注册循环会自动为 `url` 类型的配置创建 `_build_rss_fetcher`。

### 2. 架构确认（此时已自动完成）

- `_build_rss_fetcher("GitHub Trending", "source/github-trending", url, 24)` 自动创建 fetcher
- `fetch_all("daily")` 会遍历所有注册源（第 403 行 `target = [sname for sname, _ in _source_registry]`）
- `fetch_all("hn-arxiv")` 只跑 HN + arXiv，新源不受影响
- 摄入流程：RSS → `_rss_entry_to_article` → LLM filter → 质量过滤 → 写入 vault
- RSS item 的 `title`、`link`、`description`、`pubDate` 字段被 feedparser 自动解析

### 3. 验证


### 4. Build & Push

```bash

git commit -m "feat: add GitHub Trending RSS source"
git push

```

新镜像部署后，下一次 cron 运行会自动摄入 GitHub Trending 内容。

## 技术备忘

- **DS-001 源架构:** `sources.yaml` → `sources.py:_load_yaml_sources()` → 动态注册 fetcher → `fetch_all(mode)` 按模式过滤
- **RSS fetcher 复用:** `_build_rss_fetcher` 已处理重试、超时、日期过滤（`_within_last_24h`）、摘要提取
- **不影响 HN+arXiv 模式:** `fetch_all("hn-arxiv")` 硬编码只跑 "Hacker News" 和 "arXiv"
